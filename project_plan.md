# Pescados y Mariscos Arrantza

## 1. Project Description
Premium single-page website for a family-owned traditional fish market in Erandio, Bizkaia, Basque Country. The website communicates authenticity, freshness, and trust through an editorial-minimalist design inspired by Basque maritime culture. Target users are local customers seeking fresh seafood, restaurants needing wholesale supply, and visitors discovering the area. Multilingual: Spanish (default) + Euskera (Basque), with architecture ready for English and French.

## 2. Page Structure
- `/` - Home (single-page with all sections: Hero, About, Products, Why Choose Us, Seasonal, Restaurant Supply, Gallery, Testimonials, FAQ, Location, Contact, Footer)
